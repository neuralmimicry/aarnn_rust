Corrected defects
-----------------
Revision 1.1 omitted the legacy KiCad unit/position line before each
component orientation matrix. KiCad consequently interpreted the matrix
as the position line and reported an invalid symbol transform. Revision
1.2 generates both required lines for every component.

Revision 1.2 used `Power_In` as a hierarchical-label shape on every
expanded reference sheet. That name is a modern electrical pin type,
not a legal legacy `.sch` label shape, so KiCad reported "invalid label
type". Revision 1.3 uses the supported `BiDi` shape for each VSS analogue
reference and verifies every label header. It also corrects the cache
library resistor polyline from a declared 12 points to its actual 11.
