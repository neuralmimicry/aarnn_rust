# Selected community UGOT model sources

This is an unmodified selected source subset from dnorton94/ugot-robot-robomasters. See the pack lockfile for the pinned revision and per-file hashes. The MIT licence is retained. The XML is a MuJoCo model and the USDA is an OpenUSD physics articulation. Configuration estimates are explicit in config/ugot_mecanum.json and docs/PROVENANCE.md.

These files have not been run in this deliverable. Source structural checks can be run with `python3 -m unittest discover -s tests -v` from this directory after review. Actual MuJoCo/Isaac Sim execution and conversion to AARNN’s other backends require the implementation tasks. Keep original upstream code separate from modified import outputs.
